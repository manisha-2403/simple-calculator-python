# Simple Calculator using Python

A beginner-friendly command-line calculator developed using Python.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero error handling
* Invalid input handling
* Continuous calculations
* Exit option

## Technologies Used

* Python
* Python IDLE

## How to Run

1. Download or clone this repository.
2. Open `calculator.py` in Python IDLE.
3. Run the program using `F5`.
4. Select an operation from the menu.
5. Enter the required numbers.

## Example

===== SIMPLE CALCULATOR =====

Choose an operation:
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Exit

Enter your choice (1-5): 1
Enter first number: 25
Enter second number: 15
Result: 40.0
